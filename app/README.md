### This is a project accompanying Nginx Crash Course

### Commands used in the tutorial

##### start nginx
`nginx`

##### get options
`nginx -h`

##### restart nginx
`nginx -s reload`

##### stop nginx
`nginx -s stop`

##### print logs
`tail -f /usr/local/var/log/nginx/access.log`

##### restart nginx
`nginx -s reload`

##### create folder for nginx certificates
`mkdir ~/nginx-certs`
`cd ~/nginx-certs`

##### create self-signed certificate
`openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout nginx-selfsigned.key -out nginx-selfsigned.crt`

## DuckDNS and Let's Encrypt with Docker Compose

Run these commands from the repository root.

1. Copy `scripts/.env.example` to `scripts/.env` and set your real DuckDNS token, DuckDNS domain, Let's Encrypt email, Ansible user, and SSH private-key path.
2. Copy `terraform/terraform.tfvars.example` to `terraform/terraform.tfvars`. Set `security_group_cidr_ingress_ssh` to your public IP in `/32` form and set `key_name` to the AWS key pair matching `ANSIBLE_SSH_PRIVATE_KEY_FILE`. Provision the EC2 instance before deploying:
   ```bash
   terraform -chdir=terraform init
   terraform -chdir=terraform apply
   ```
3. Deploy with `./scripts/ansible_exec.sh`. The script reads `scripts/.env`, validates the required values, gets the provisioned IP from Terraform, generates the configured Ansible inventory, then runs the playbook. The secrets are not printed. Use this setup flow rather than invoking the playbook directly, since the inventory is generated by the wrapper.
4. The Ansible playbook starts Nginx, creates the certificate through the HTTP-01 webroot challenge, and switches Nginx to HTTPS.
5. Certificate renewal runs daily and the renewal hook restarts Nginx.

If a DuckDNS token was exposed, revoke it, replace `DUCKDNS_TOKEN` in `scripts/.env`, then rerun `./scripts/ansible_exec.sh` from the repository root. The playbook updates the deployed `scripts/.env`, which `cert.sh` reads when run; the scheduled Certbot renewal does not use the DuckDNS token. `scripts/.env` is ignored by Git.
